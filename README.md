# nih

## Flappy Bird

A browser replica of Flappy Bird in a single file with no dependencies.

**Play:** open `index.html` in any modern browser (double-click it, or serve the folder with any static server).

**Controls:** Space, Up arrow, W, mouse click, or tap to flap. Tap again after "Game Over" to restart.

Your best score is saved in the browser via localStorage.
